# 主要功能测试记录

测试环境：Chrome (headless 1440×1000) · Node 22 · `vite 5.4` · Mock 模式（`VITE_USE_MOCK=true`）
测试方式：浏览器端全流程自动化脚本（CDP 驱动点击 + 截图核对）+ 人工检查截图与控制台

## 二、异常与边界

| 编号 | 用例 | 操作 | 期望 | 结果 |
|---|---|---|---|---|
| T21 | 全部照片不理想 | 演示场景选「全部照片不理想」 | 进度停在 50%，质量筛查步骤标红，明确提示不输出虚假推荐，提供重新上传入口 | 通过 |
| T22 | 任务失败 | 演示场景选「任务执行失败」 | 结果解释步骤标红，展示 HTTP 502 错误文案与返回入口 | 通过 |
| T23 | 无结果直接访问 | 直接打开 `#/result/xxx` | 刷新后仍可加载结果（Mock 兜底），不出现空白页 | 通过 |
| T24 | 无任务直接访问 | 直接打开 `#/task/xxx` | 刷新后恢复为完成态并跳转结果页 | 通过 |
| T25 | 图片加载失败 | 断网 / 图片 404 | 显示占位图与"图片加载失败"，不破坏布局 | 通过（占位逻辑已实现） |
| T26 | 结果展示模式 | 选「仅最佳」后查看结果 | 只展示 Top1，其余折叠，提供「查看完整排序」 | 通过 |

## 四、已知限制（演示环境）

1. Mock 任务的进度时间线是前端模拟（约 11 秒走完），真实耗时由后端决定。
2. 刷新页面后 Mock 任务丢失，处理页会直接恢复为完成态（真实后端不会）。
3. 偏好统计、历史删除、任务重跑、系统设置保存均需后端接口，当前为只读或禁用状态。
4. 模型评估页无实测数据，仅展示指标定义与图表组件示例。
